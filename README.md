hop Expense Tracker

Тема проекта

shop-expense-tracker — сервис учёта расходов на покупки.



Описание

Проект предназначен для записи покупок, хранения стоимости товаров и контроля общих расходов.



Основные возможности

Добавление покупок.

Хранение названия и стоимости товара.

Просмотр списка покупок.

Подсчёт общей суммы расходов.

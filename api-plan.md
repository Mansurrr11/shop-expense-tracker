API Plan

Предварительные маршруты

Метод	Маршрут	Назначение

GET	/purchases	Получить список покупок

GET	/purchases/{id}	Получить покупку по ID

POST	/purchases	Добавить покупку

PUT	/purchases/{id}	Изменить покупку

DELETE	/purchases/{id}	Удалить покупку

Данные покупки

id — идентификатор.

name — название товара.

category — категория.

price — стоимость.

date — дата покупки.



Это предварительный план API. Реализация будет добавлена на следующих этапах.
